## Portfolio Sections

The website is organized into interactive sections accessible from the navigation bar:

1. **Hello / Home** — Profile introduction, skills, coding activity, statistics, resume download, and GitHub link.
2. **About** — Personal introduction, services, specializations, tools, platforms, and technical skills.
3. **Projects** — Detailed project descriptions with live links, previews, problems, tasks, solutions, and technology information.
4. **Experience** — Professional experience, education, achievements, and certifications.
5. **Contact** — Email, GitHub, LinkedIn, location, resume download, coding profiles, and quick statistics.
